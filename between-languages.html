03. Web Design
Between Languages
An interactive website combining video and data visualization to reveal how language-switching reflects personal identity and social context, making the often-overlooked patterns of multilingual communication visible and accessible.
ROLE
Designer
YEAR
2025
TOOLS
Readymag, Illustrator, Claude Code
CATEGORY
Web Design
Data Visualization
This project explores how my daily conversations shift between multiple languages and how identity, context, and time of day influence the way I communicate.
Section 01
The website consists of two interconnected sections. The first introduces the four languages I speak—English, Mandarin, Cantonese, and “Animal Language” with my cat. Each language page features a video recording of me speaking, revealing differences in tone, expression, and rhythm through the movement of my mouth and speech patterns.
Section 02
The second section is an interactive data map that visualizes language-switching behavior using a system of simple shapes and colors. Visitors can explore patterns of communication throughout the day and see how different social contexts shape the languages I use.
Let’s work together.
